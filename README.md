# pairwise-day-night-cycle

太阳落山后天空还亮着，昼夜时间按帧累加，掉帧时太阳停在同一位置；光照强度曲线在日落点之后还保持 0.3，天空已经全黑地面仍然发亮；阴影方向按固定向量插值，太阳落到地平线以下时阴影没有翻转；环境光探针按白天烘焙，夜里仍然用白天的天光；月亮升起后没有独立光源，夜景只有环境光；天气系统下雨时没有压暗太阳，雨天的正午还是刺眼；时区按本地时间算，跨时区玩家的日出时间差好几个小时；黄昏过渡只有 3 秒，颜色从橙直接跳到黑；烘焙光照没有随时间重算，静态物体的影子永远停在中午；联机时各客户端各自跑时间，同一场比赛一边白天一边黑夜。gameplay/day_night_cycle.py 是核心，tests/test_day_night_cycle.py 15个红。要修的是：真实时间；曲线连续；阴影翻转；环境光随时段；月亮光源；天气影响；服务器时区；平滑过渡；按时段重烘焙；网络同步时间。

## 运行

```bash
python -m pytest tests -q
```
